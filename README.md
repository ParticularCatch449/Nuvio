# Nuvio - TVFlix Collections Builder

Welcome to the **Nuvio TVFlix Builder**, a powerful tool designed to help you interactively build, manage, and configure collections for TVFlix. 

## 🚀 Live Application

You can easily access the live and official version of Nuvio below.
**Link:** [https://nuvio.tvflix.co.uk](https://nuvio.tvflix.co.uk)

## ✨ Features

- **Collection Builder:** Create and manage customized JSON configuration and data files.
- **Modern UI:** A clean, responsive interface powered by React 19, Tailwind CSS, and Shadcn UI.
- **Fast Performance:** Lightning-fast builds via Vite.
- - **Assets:** [Images](https://tvflix.co.uk/Assets/)

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + Shadcn UI
- **Animations:** [Motion](https://motion.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 📝 Local Development

If you want to run this project locally on your machine, follow these steps:

1. **Download / Clone the Repository**
   Extract the provided `.zip` source or clone it via Git.

2. **Install Dependencies**
   Navigate to the project root and install the required modules:
   ```bash
   npm install
   ```

3. **Start Development Server**
   Start the local dev server (default port is usually 3000 or 5173 depending on your environment):
   ```bash
   npm run dev
   ```

4. **Build for Production**
   Ready to deploy? Run the build command to generate the optimized static files in the `dist/` directory:
   ```bash
   npm run build
   ```

5. **Deployment**
   Upload the contents of the `dist/` directory to any static hosting provider (e.g., Vercel, Netlify, Cloudflare Pages, or a standard web server).
